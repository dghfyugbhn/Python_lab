## **Краткие теоретические сведения** 

- **Условный оператор if-elif-else:** Используется для проверки логических условий и ветвления алгоритма. Конструкция elif связывает последовательные проверки без лишней вложенности отступов. Блок else выполняется, если ни одно из условий не подтвердилось. Обязательно двоеточие (:) и отступы в 4 пробела. 

- **Цикл while:** Выполняет блок выражений до тех пор, пока проверяемое условие истинно (True). Для экстренного выхода из цикла применяется оператор break, а для перехода к следующей итерации - continue. 

- **Пользовательские функции (def):** Многократно используемые блоки кода с собственным именем. Функция объявляется ключевым словом def, принимает параметры и возвращает результаты вычислений оператором return. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания её назначения.
